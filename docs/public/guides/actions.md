---
title: Run actions
description: Trigger GitHub workflows, such as a deploy, from Pages CMS.
---

Actions are buttons that start a GitHub Actions workflow, such as a deploy. They appear in the sidebar, on the Overview, or on collection, entry, file and media pages, depending on how they're [configured](/docs/configuration/actions/).

1. Choose the action's button.
2. Fill in any inputs and confirm.
3. Follow the run in **Actions**, or on GitHub.

A started run hasn't necessarily succeeded: check its status. Use **Cancel run** to stop it, unless the action disables cancelling, and **Run again** to repeat it with the same inputs.

Managers can run any action. Collaborators can run actions only on hosted Pro projects, when their [role](/docs/guides/roles/) allows it, and can cancel only their own runs.
