---
title: Manage media
description: Upload, select, move, rename and delete images and files.
---

Media libraries appear in the sidebar. Each library maps to a folder in the repository, or to cloud storage on hosted Pro projects.

## Browse and upload

Open a library to browse its folders. Use **Upload** to add files and **New folder** to organize them. A library can limit which file types it accepts; if an upload is refused, ask whoever manages the project which types are allowed.

## Use media in content

In an image or file field, choose **Select** to pick an existing file from the library, or upload a new one directly from the field. In a rich-text field, type `/` to insert an image.

The field stores the file's public path, such as `/uploads/photo.jpg`. Previews inside Pages CMS can use temporary URLs; those are never written to your content.

## Move, rename and delete

To move a file within its library, open the file’s menu, choose **Move to…**, expand the folder tree, select the destination and choose **Move**. In list or grid view, you can also drag a file onto a folder or onto an ancestor in the breadcrumb, including the library root.

Use **Rename** to change the filename or **Delete** to remove the file. Check your content for links to the old path and update them when you move, rename or delete a file.
