For editors working on a project someone else has set up.

## Find your content

Sign in at the address your team gave you. If you were invited by email, use that address. Open the project and check the branch menu: you edit one branch at a time, usually `main`.

The sidebar lists what you can edit:

- **Collections** hold many entries of one kind, such as posts or products.
- **Files** are single pages or settings, such as the home page.
- **Media** libraries hold images and documents.

If something is missing, ask whoever manages the project.

## Edit and save

1. Open an entry or a file.
2. Change the fields. Errors show under each field.
3. Choose **Save**.

Each save is a commit. When it reaches the live site depends on how the site is deployed.

- **Drafts.** Unsaved changes stay in your browser, so you can close the tab and come back. A **Draft** badge marks them; from there you can download or discard the draft. Drafts don't sync to your other devices.
- **Conflicts.** If someone else saved the same file while you were editing, Pages CMS shows the conflicting fields. Pick a version for each, then save.
- **Rich text.** Switch between **Editor** and **Source**; both edit the same content. Type `/` to insert blocks and snippets.

## Create, rename and delete

Choose **New entry** in a collection to create one. Its filename is generated, usually from the title. Use an entry's menu to rename or delete it.

Renaming or deleting doesn't update links to the file elsewhere on the site.
